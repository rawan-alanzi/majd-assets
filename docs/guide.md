# دليل استخدام ثيم مجد

## البدء
1. ثبّت الثيم من متجر ثيمات سلة.
2. تُضاف الأقسام الأساسية للصفحة الرئيسية تلقائيًا بمحتوى تجريبي.
3. افتح **محرر الثيم** من لوحة تحكم متجرك، وعدّل كل قسم من إعداداته المرقّمة.

## إعدادات الثيم العامة
- **الهوية والنمط العام:** اختر أحد الأنماط الجاهزة الثمانية، ويُعتمد اللون الأساسي من هوية متجرك.
- **الألوان المخصصة:** فعّلها لتغيير الألوان الثانوية والخلفيات والنصوص.
- **الهيدر والفوتر:** اختر الشكل المناسب وفعّل العناصر التي تحتاجها.
- **بطاقة المنتج وصفحة المنتج:** تحكم في عدّاد الخصم وتنبيه الكمية المتبقية والعرض السريع.
- **السلة:** فعّل السلة الجانبية وشريط الشحن المجاني واقتراحات إكمال الطلب.

## أقسام الصفحة الرئيسية
أضف أي قسم من زر **«إضافة عنصر جديد»** في المحرر. لكل قسم صورة توضيحية ووصف مختصر، وإعداداته مرقّمة بالترتيب، وتظهر الحقول المرتبطة بالخيار الذي تحدده فقط.

| القسم | الاستخدام |
|---|---|
| البنر الرئيسي | شرائح صور أو فيديو أو منتجات أو نصوص |
| مزايا المتجر | الشحن، الدفع الآمن، الاسترجاع |
| التصنيفات | عرض تصنيفات متجرك تلقائيًا أو يدويًا |
| عرض المنتجات | الأحدث، الأكثر مبيعًا، المخفّضة، من تصنيف أو ماركة |
| عروض محدودة الوقت | منتجات مخفّضة مع عدّاد تنازلي |
| بنرات إعلانية | بنر واحد أو أكثر بتخطيطات متعددة |
| المنتجات بالتبويبات | عدة مجموعات منتجات في قسم واحد |
| قصتنا | صورة مع نص للتعريف بالمتجر |
| آراء العملاء | آراء عملائك الحقيقية |
| العلامات التجارية | ماركات متجرك أو شعارات مخصصة |
| القائمة البريدية | اشتراك مع كود خصم أو رابط قائمة بريدية |
| أرقامنا، بنر العد التنازلي، بطاقات تعريفية، فيديو تعريفي، معرض الصور، الأسئلة الشائعة، شريط متحرك، مقارنة المنتجات، شاهدتها مؤخرًا، المدونة | أقسام إضافية حسب حاجتك |

## الصور التجريبية
تظهر صور توضيحية مكان أي صورة لم تُرفع بعد. ارفع صورك من إعدادات كل قسم، أو عطّل خيار **«صور تجريبية جاهزة»** من إعدادات الهوية.

## المقاسات المقترحة للصور
- البنر الرئيسي: 1920×900 للكمبيوتر، 900×1200 للجوال.
- البنرات الإعلانية: 1200×800.
- التصنيفات: 600×600.
- قصتنا: 1000×1100.

## الدعم
للمساعدة تواصل معنا عبر البريد الإلكتروني أو المحادثة المباشرة الموضحة في صفحة الثيم.
